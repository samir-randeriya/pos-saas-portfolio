# POS SaaS Portfolio

A mini POS SaaS application built with **Laravel 10** and **React**.

## Features
- User authentication
- Subscription plans (Free Trial, Silver, Gold)
- Razorpay payment integration
- Role-based access (Admin / Client)
- Admin impersonation
- Modular dashboard based on plan

## Tech Stack
- Backend: Laravel 10 (API)
- Frontend: React (Vite)
- Auth: Laravel Sanctum
- Payments: Razorpay
- Database: MySQL

## Project Structure
/backend   → Laravel API  
/frontend  → React frontend
